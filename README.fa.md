وقتی Claude به فارسی/عربی جواب می‌دهد، متن **چپ‌چین (LTR)** نمایش داده می‌شود و به‌هم‌ریخته به‌نظر
می‌رسد. این ابزار زبانِ هر پاراگراف را تشخیص می‌دهد و جهتش را درست می‌کند: **فارسی → راست‌چین،
انگلیسی و کد → چپ‌چین.** یک دکمهٔ شناور کوچک هم می‌گذارد تا هر وقت خواستی بین سه حالت **خودکار /
راست‌چین / خاموش** جابه‌جا شوی.

روی هر دو نسخه کار می‌کند: **claude.ai (مرورگر)** و **نرم‌افزار دسکتاپ Claude**.

## ویژگی‌ها

- 🎯 **تشخیص جهت پاراگراف‌به‌پاراگراف** — جهت هر پاراگراف بر اساس **اکثریت حروفش** تعیین می‌شود؛ پس
  جملهٔ فارسی‌ای که *با یک واژهٔ انگلیسی شروع می‌شود* (مثل «Python یک زبان است») هم درست راست‌چین می‌شود.
- 🔀 **سه حالت** — خودکار، راست‌چین، خاموش. انتخابت ذخیره می‌شود.
- 🧮 **کد و ریاضی چپ‌چین می‌مانند** — `pre`، `code` و فرمول‌های KaTeX هرگز نمی‌چرخند.
- 📊 **اصلاح جدول‌ها** — ستون‌های جدول‌های فارسی راست‌به‌چپ چیده می‌شوند.
- ⚡ **سریع** — هنگام استریمِ پاسخ فقط بخشِ تغییریافتهٔ صفحه دوباره پردازش می‌شود.
- 🧩 **مقاوم** — به کلاس‌های داخلی CSS کلاد وابسته نیست؛ پس با به‌روزرسانی رابط کاربری نمی‌شکند.
- 🔒 **حریم خصوصی** — بدون سرور و بدون ردیابی. فقط حالتِ انتخابیِ تو به‌صورت محلی ذخیره می‌شود.

## دکمهٔ سوییچ

- **کلیک چپ** روی دکمهٔ شناور → منوی سه‌حالته باز می‌شود.
- **کلیک راست** → چرخش سریع بین خودکار ← راست‌چین ← خاموش.
- با **کشیدن**، دکمه را هر جا خواستی ببر؛ جایش ذخیره می‌شود.

| حالت | نماد | کاری که می‌کند |
|------|:---:|----------------|
| **خودکار** | ☉ | هر پاراگراف بر اساس زبان خودش. بهترین حالت برای متن ترکیبی فارسی/انگلیسی. *(پیشنهادی)* |
| **راست‌چین** | ← | هر متنی که فارسی/عربی داشته باشد به‌زور راست‌چین می‌شود؛ متن انگلیسیِ اکثریت دست‌نخورده می‌ماند. |
| **خاموش** | ○ | همه‌چیز به حالت اصلی Claude برمی‌گردد. |

## نصب — نسخهٔ مرورگر (claude.ai) ✅ پیشنهادی

روش تمیز و همیشگی. یک‌بار نصب کن، همیشه کار می‌کند.

### کروم / اج / بریو (Chrome / Edge / Brave)

1. **این پروژه را دانلود کن** (دکمهٔ سبز **Code** ← *Download ZIP* و بعد اکسترکت؛ یا `git clone`).
2. صفحهٔ اکستنشن‌های مرورگر را باز کن:
   - کروم → `chrome://extensions`
   - اج → `edge://extensions`
   - بریو → `brave://extensions`
3. **حالت توسعه‌دهنده (Developer mode)** را (گوشهٔ بالا-راست) روشن کن.
4. روی **Load unpacked** بزن.
5. پوشهٔ **`extension`** داخل همین پروژه را انتخاب کن.
6. برو به `claude.ai` (اگر باز بود، یک‌بار تب را **رفرش** کن).
   دکمهٔ گرد نارنجی در لبهٔ راستِ صفحه ظاهر می‌شود.

> پوشهٔ `extension` را پاک نکن — مرورگر اکستنشن را از همان‌جا می‌خواند.

### فایرفاکس (اختیاری / آزمایشی)

1. برو به `about:debugging#/runtime/this-firefox`.
2. روی **Load Temporary Add-on…** بزن.
3. فایل `extension/manifest.json` را انتخاب کن.
   (افزونهٔ موقت با بستنِ فایرفاکس پاک می‌شود.)

## نصب — نرم‌افزار دسکتاپ Claude

**چرا اینجا فرق دارد؟** نرم‌افزار دسکتاپ Claude از نظر امنیتی قفل شده است (دیباگ از راه دور غیرفعال و
یکپارچگی فایل‌ها بررسی می‌شود)، بنابراین نمی‌شود هیچ اکستنشن یا افزونهٔ دائمی نصب کرد. تنها راهِ ممکن،
اجرای یک اسنیپت کوتاه در **کنسول DevTools** خودِ برنامه است.

1. برنامهٔ دسکتاپ Claude را باز کن.
2. در هر جای پنجره **راست‌کلیک** کن ← **Inspect Element**.
   (این گزینه چون `allowDevTools` روشن است دیده می‌شود — اگر نبود، پایین را ببین.)
3. بالای پنجره روی تب **Console** کلیک کن.
4. فایل [`desktop/claude-desktop-rtl.js`](desktop/claude-desktop-rtl.js) را باز کن، **همه‌اش را انتخاب**
   (Ctrl+A) و **کپی** (Ctrl+C) کن، بعد داخل کنسول کلیک کرده و **Paste** (Ctrl+V) کن.
   - بار اول ممکن است بخواهد عبارت **`allow pasting`** را تایپ کنی — تایپ کن، Enter بزن، بعد دوباره Paste کن.
5. **Enter** بزن. دکمهٔ گرد در لبهٔ راست ظاهر می‌شود. تمام!

می‌توانی پنجرهٔ DevTools را ببندی؛ دکمه و اصلاحات باقی می‌مانند.

<details dir="rtl">
<summary>گزینهٔ «Inspect Element» را نمی‌بینی؟ اول DevTools را روشن کن (یک‌بار)</summary>

این فایل را بساز:

`%LOCALAPPDATA%\Claude-3p\developer_settings.json`

با محتوای:

```json
{ "allowDevTools": true }
```

سپس برنامهٔ Claude را کامل ببند و دوباره باز کن.
</details>

> **محدودیت دسکتاپ:** چون برنامه اجازهٔ تزریق خودکار نمی‌دهد، این اسنیپت با **بستنِ کاملِ** برنامه پاک
> می‌شود. هر بار که Claude را از نو باز می‌کنی یک‌بار دیگر Paste می‌کنی (تا وقتی برنامه باز است لازم
> نیست کاری کنی). برای استفادهٔ روزمرهٔ بی‌دردسر، **نسخهٔ مرورگر** بهتر است.

راهنمای کامل گام‌به‌گام (همراه با روشن‌کردن DevTools): [`desktop/HOW-TO-DESKTOP.md`](desktop/HOW-TO-DESKTOP.md).

## چطور کار می‌کند؟

هستهٔ کار، صفت استاندارد `dir` در HTML به‌همراه یک تشخیص‌دهندهٔ جهت است. برای هر عنصر متنیِ بلوکی
(پاراگراف، فهرست، عنوان، سلول جدول…) موتور تعداد حروف قویِ راست‌به‌چپ را در برابر چپ‌به‌راست می‌شمارد
(کاراکترهای ضعیف مثل ارقام فارسی را نادیده می‌گیرد) و بر همان اساس `dir` را روی `rtl`، `ltr` یا `auto`
می‌گذارد، سپس با کمی CSS تراز متن را هم هماهنگ می‌کند. کد و ریاضی به‌صراحت چپ‌چین نگه داشته می‌شوند.
یک `MutationObserver` اصلاح را روی پیام‌های در حال استریم دوباره اعمال می‌کند — اما فقط روی بخشی از DOM
که واقعاً تغییر کرده، تا روی چت‌های طولانی روان بماند. چون عناصر عمومی HTML را هدف می‌گیرد نه کلاس‌های
CSS کلاد، به‌روزرسانی‌های رابط کاربری آن را نمی‌شکنند.

## توسعه و تست

```bash
node test/cdp-test.js      # اجرای ۳۳ بررسی در Chrome واقعی (بدون نیاز به npm install)
node test/make-icons.js    # ساخت دوبارهٔ آیکون‌ها
```

هارنس تست یک مرورگر واقعی را از طریق Chrome DevTools Protocol و با WebSocket داخلی Node (بدون هیچ
وابستگی) هدایت می‌کند، هر حالت را اعمال می‌کند، `direction` محاسبه‌شده را می‌خواند و اسکرین‌شات‌ها را در
`test/shots/` ذخیره می‌کند.

اگر `shared/rtl-engine.js` را ویرایش کردی، آن را در `extension/rtl-engine.js` و
`desktop/claude-desktop-rtl.js` کپی کن (نسخهٔ دسکتاپ فقط یک خط سرآیند اضافه دارد) و تست‌ها را دوباره اجرا کن.
