بازگشت (Recursion) چیست؟

بازگشت یعنی وقتی یک تابع خودش را دوباره صدا می‌زند. این روش برای حل مسائلی که می‌توان آن‌ها را به نسخه‌های کوچک‌تر از خودشان تقسیم کرد بسیار مفید است.

برای مثال، فاکتوریل عدد n برابر است با n × (n-1)! که خودش یک تعریف بازگشتی است.

  • هر تابع بازگشتی باید یک «حالت پایه» داشته باشد.
  • بدون حالت پایه، تابع تا بی‌نهایت اجرا می‌شود.
function factorial(n) {
  if (n <= 1) return 1;      // base case
  return n * factorial(n-1); // recursive step
}
